# GST Annual Return & ITC Reconciliation Tool — Handover

James & James LLP · built 20 Nov 2026 · Loader v0.7, workbook template 2026.11.20-7

## What it is
Two pieces:
1. **GST_Annual_Return_Loader.html**: a single offline HTML page (Chrome / Edge; no install, no Excel 365 needed; files never leave the PC). It has two modes, picked on the first screen:
   - **Monthly ITC reconciliation**: GSTR-2B JSON(s) for one or more months, plus purchase register(s) in any format (column mapping), produce *ITC_Recon_<GSTIN>_<period>.xlsx*. That workbook has Summary (ITC position and claimable ITC), Recon_Purchases, Recon_Suppliers, Month_wise, Books_Purchase and RAW_2B.
   - **Annual return**: GSTR-1 JSON/ZIP (PY, CY, NY), GSTR-2B JSON (CY + NY Apr–Nov), GSTR-3B PDFs, the portal auto-drafted GSTR-9 JSON and registers produce *GSTR9_<GSTIN>_<FY>.xlsx*. Step 04 reads the finished, saved workbook back and produces the **GSTR-9 upload JSON**, with an edit check (formulas vs template, fingerprint + HMAC seal of imported data, audit list of adjustments).
2. **GST_Annual_Return_Workbook.xlsx**: the macro-free template (Excel 2010+), embedded in the loader.

## Source layout
```

  src/main.ts              UI: modes, file drop, coverage grid, register mapping, build, JSON step
  src/build.ts             classify files; buildWorkbook (annual); buildItc (monthly); readReconState

  src/gstr2b.ts            GSTR-2B JSON → RAW_2B rows (keys 8A, 8A+8C, 6A1, 8G, 8G+8H1)
  src/gstr3b.ts            3B PDF text lines (pdf.js) → 3.1/3.1.1/4A-4D/5 + 6.1 payment
  src/portal9.ts           portal auto-drafted GSTR-9 JSON → RAW_Portal9 (paths in paths.json)
  src/register.ts          register reader (.xlsx/.csv), header detection, column synonyms, normalisation
  src/recon.ts             matching engine (purchases vs 2B, sales vs GSTR-1, monthly), manual codes, supplier totals
  src/gen9.ts              finished workbook → GSTR-9 upload JSON (field lists copied from GSTN offline tool v2.2)
  src/integrity.ts         fingerprints, HMAC seal, formula diff vs template, adjustments audit
  src/xlsx.ts              style-preserving XLSX writer (writeRows / fillTable / setCells) + cached-value Reader
  src/rowmap.json, paths.json  GSTR-9 key → (sheet,row) and key → JSON path (generated by build_workbook.py)
  template/                the two .xlsx templates embedded in the HTML
  test/                    tsx scripts (e2e.ts, gen.ts, integ.ts, itc.ts, t3b.ts)
workbook/
  build_workbook.py        generates GST_Annual_Return_Workbook.xlsx (openpyxl). Writes rowmap.json/paths.json
  build_itc_template.py    generates ITC_Recon_Template.xlsx (reuses the recon-sheet code)

```
Build: `cd loader && npm i && npx vite build` produces `dist/index.html`. Python scripts have absolute paths (/home/claude/...), so adjust them before running elsewhere. After changing the workbook, copy the .xlsx and rowmap.json/paths.json into loader/template and loader/src.

## Key decisions (agreed with Tobin)
- No macros and no Excel 365 functions (SUMIFS/INDEX/MATCH only). The browser does the parsing, because Power Query "From PDF" isn't available to every user.
- Hosting: the single HTML on a shared drive works offline; optional Cloudflare Pages at gst.jjglobal.in behind Cloudflare Access.
- Branding: James & James design system (#2C388E, Onest on the web page, Arial in Excel). Every sheet says "Prepared by James & James LLP".
- ICAI Technical Guides followed: 7I includes 7E; 7F = 4N − 4G + 10 − 11; 9Q = Table 9 + Table 14; 12E/14S = 7J; 8B = 6B only; rule 37/37A reclaims go to 6H, other prior-year reclaims to 6A1; next-FY credit notes (Apr–Nov) are tagged 11-REVIEW.
- GSTR-9C FY 2025-26: self-certified. No Part B / DSC in the offline tool, so the JSON can be generated directly (not built yet).
- Matching order: manual codes, then invoice no. (punctuation ignored), digits, last digits/tail (amounts agree), GSTIN+date+amount, number+amount with GSTIN differing, supplier totals, then hints. Missing GSTIN is taken from 2B by supplier name or by invoice no. + amount. Zero-tax lines are not compared. Tolerance ₹1.
