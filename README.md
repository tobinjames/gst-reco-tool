# GST Annual Return & ITC Reconciliation Tool

James & James LLP. Offline, single-page HTML tool for monthly ITC reconciliation (GSTR-2B vs purchase register) and GSTR-9 annual return preparation, with a macro-free Excel workbook template.

- `loader/` Vite + TypeScript app, builds to one HTML file
- `workbook/` Python (openpyxl) scripts that generate the Excel templates
- Live tool: https://tobinjames.github.io/gst-reco-tool/ (latest `main`, redeployed on every push by `.github/workflows/pages.yml`; files are read in the browser and never uploaded)
- Built tool: download it from the repo's Releases page (one HTML file per version)
- `docs/HANDOVER.md` full handover: architecture, key decisions, open items

## Build and check

```
cd loader
npm ci
npm run check    # formatting, type check, all tests, build -> dist/index.html
```

`npm test` runs the tests only. Real-file test cases live in `loader/test/cases/` (see the README there).
The workbook templates are generated by `python3 workbook/build_workbook.py` and `build_itc_template.py`.
